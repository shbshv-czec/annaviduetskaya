# Сайт Анны Видуецкой

Одностраничный сайт-визитка. Всё в одном файле — `index.html` (HTML + CSS + JS инлайн). Ассеты (фото, видео, обложки) — в `assets/`.

## Структура блоков (сверху вниз)
1. Первый экран (hero) — портрет + имя + кнопки (бирюзовая «Записаться», WhatsApp)
2. Книга «Легче воздуха» — обложка + золотая медаль Amazon
3. Обо мне — фото + история (попап «Моя история» на линованной бумаге) + плитки-цифры (3/4/2)
4. Консультации — рубящая цитата + 3 запроса (карточки с scroll-проявлением) + панель «жду вас»
5. Выступления — заголовок + шоурил + галерея сцен + карточки тем + плашка для СМИ
6. Подкаст (YouTube) — горизонтальная карусель гостей
7. Telegram — тёмная секция + телефон с прокруткой
8. Футер — контакты, разделы, соцсети

## Дизайн-система
- Шрифты: Cormorant (заголовки, `--serif`), Lora (текст, `--text`), Manrope (UI, `--sans`)
- Цвета: `--gold`, `--ink`, `--teal` (акцент), `--cream`/`--teal-soft` (фоны)
- Типо-шкала: классы `.t-display / .t-h1 / .t-h2 / .t-h3 / .t-lead / .t-body / .t-eyebrow` (шкала Parloa)
- Карточки-описания: чёрный квадрат-маркер в углу + scroll-scrub проявление с блюром (JS внизу файла)

## Оставшиеся заглушки (найти по `[[...]]`)
- `[[ССЫЛКА YouTube]]`, `[[ССЫЛКА ВКонтакте]]` — соцсети в футере
- `[[ФАЙЛ: резюме PDF]]`, `[[ССЫЛКА: фотобанк]]` — плашка «Для организаторов и СМИ»
- `[[ССЫЛКА на YouTube-канал]]` — кнопка «Смотреть все выпуски»
- Кнопка «Купить книгу» — `href="#"`

## Известные ограничения
- `assets/tg-scroll.mov` (QuickTime) не проигрывается в Chrome — сейчас показывается обложка `tg-cover.jpg`. Нужен **MP4 (H.264)** для скролл-видео в Telegram.
- Мобильная версия проверена на 390px для основных блоков; галерея выступлений и модалка истории — можно допилить.
