# Сайт Анны Видуецкой

Одностраничный статический сайт. Всё в `index.html` (разметка + CSS + JS
инлайн), медиа — в `assets/`. Сборки и зависимостей нет: что в репозитории,
то и на сайте.

**Боевой адрес:** https://shbshv-czec.github.io/annaviduetskaya/
Деплой: push в `main` → GitHub Pages.

Перед каждым коммитом:

```bash
python3 scripts/check.py
```
